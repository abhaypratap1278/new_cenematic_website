# Abhaypratap Sikarwar — The Engineering Series

A cinematic, streaming-inspired personal portfolio built with React, TypeScript, Vite, Framer Motion and Lenis. Personal content and assets were populated from the supplied original portfolio ZIP.

## Run locally

1. Install Node.js LTS.
2. Open this folder in VS Code.
3. In the terminal run `npm install`, then `npm run dev`.
4. Open the localhost URL printed by Vite.

## Build for deployment

Run `npm run build`. The production files are created in `dist/`.

## Personal assets

Profile and event photos are in `public/portfolio/images/`; certificate PDFs are in `public/portfolio/certificates/`. The resume PDF was not present in the supplied original ZIP, so no resume file has been fabricated.

Main portfolio content is in `src/data/portfolio.ts`.
