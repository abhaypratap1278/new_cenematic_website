# Abhaypratap Sikarwar — The Engineering Series

A cinematic, streaming-inspired personal portfolio built with React, TypeScript, Vite, Framer Motion and Lenis.

## Run Locally

1. Install Node.js LTS.
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the localhost URL shown by Vite.

## Build for Deployment

Run `npm run build`. The production files will be generated in the `dist/` folder.

## Personal Assets

- Profile and event photos: `public/portfolio/images/`
- Certificate PDFs: `public/portfolio/certificates/`
- Main portfolio content: `src/data/portfolio.ts`

## Deployment

This project can be deployed using Netlify with:

- Build command: `npm run build`
- Publish directory: `dist/`
